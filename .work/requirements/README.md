# Raw Requirements Workspace

Folder kerja sementara untuk mengumpulkan mentahan requirement dan aset (gambar/referensi) sebelum diproses ke tahap formal (G1–G5 / to-spec / to-tickets / wdi-autopilot).

## Struktur Penyimpanan
- `prompt-XX-<topik>.md`: Berkas catatan mentahan per sesi/prompting dari pengguna.
- `images/`: Berkas visual / screenshot referensi UI yang disertakan.

## Pengingat Kebijakan Repo Publik
Repository ini adalah publik. Pastikan teks dan gambar yang disimpan:
1. Tidak memuat data pribadi / jemaat riil (nama asli anggota, nomor HP, foto wajah anggota, rekening bank, QR payment, doa jemaat).
2. Gunakan data sintetis/dummy jika menyertakan contoh kartu atau formulir.
