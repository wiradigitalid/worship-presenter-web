# prior-knowledge

Arsip terakhir korpus **sebelum** metode WDI. Bukan `.what/` / `.how/`. Bukan otoritas.

Pemilik repo menaruhnya di **root**, bukan `_bmad-output/prior-knowledge/`, supaya path-nya enak dibaca. Isi mencerminkan root lama: `docs/` dan `_bmad-output/` (planning, implementation, specs, brainstorming).

Masuk ke korpus hidup hanya lewat skill yang punya slot. Pensiun folder ini: tiga syarat di `corpus-guide.md` plus `DEC-`.

Validator V24 memindai markdown di sini karena path-nya bukan `_bmad-output/` di root. Kutipan usang di arsip akan merah sampai metode mengecualikan `prior-knowledge/` — itu bukan alasan menulis ulang riwayat.
