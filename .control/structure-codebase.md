## Containers

Headings are the `built: true` containers in `components.yaml` (DEC-003). Folders `cmd/api/`, `spa/`, `workers/pptx/` are **not on disk yet** — as-built code still lives under `src/`. That drift is the cutover wave.

### api

Go always-on process + SQLite. `built: true`. Target: `cmd/api/`. As-built: `src/app/api/**` + `src/lib/**` + `src/proxy.ts`.

```text
src/
├── proxy.ts                  # ★ as-built AD-5 gate (target: Go matcher)
├── app/api/<resource>/route.ts
└── lib/
    ├── db/                   # SQLite startup DDL (AD-9)
    └── slide-plan.ts         # ★ LC-16 planner
```

**Flow (target):** Go gate → JSON handlers → SQLite `DB_PATH`. Plan stays in `api`; PPTX is not this container.

### spa

React SPA. `built: true`. Target: `spa/`. As-built: `src/app/(operator)/`, `src/app/(projected)/`, `src/components/`.

```text
src/app/
├── (operator)/               # Operator chrome (AD-24)
└── (projected)/              # room display
src/components/               # UI
```

**Flow:** browser → JSON `api` + session cookie. MUST NOT open SQLite (AD-30).

### pptx-worker

On-demand Node child. `built: true`. Target: `workers/pptx/`. As-built: `src/lib/pptx.ts` inside the Next process.

```text
src/lib/pptx.ts               # ★ as-built PptxGenJS (target: child that draws a finished plan)
```

**Flow (target):** `api` execs worker with a finished plan → PPTX file → exit. MUST NOT open SQLite.
